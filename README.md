# Two-row Header

English | [中文](README.zh.md)

Place native conversation actions and utilities on separate header rows. Controls retain their original order and behavior and can wrap further when space is limited.

The plugin uses DSH extension points and leaves with its bundle when disabled. It adds no tools, model prompts, external requests, or conversation records.
